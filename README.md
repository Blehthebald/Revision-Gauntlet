# Revision-Gauntlet V1
A competitive Elo-based Revision league

## Revision Gauntlet rules 
-Two players select an exam paper that they want to do and race to finish  
-A predetermined "Penalty time" is decided (e.g 2 minutes)\
-When the first person finishes their paper, they start a timer that ends when the second player is finished\
-Both players mark their exam papers\
-The second player loses a mark for every set of penalty time has been exceeded (If the penalty time was set to 2 minutes, the second player to finish loses a mark every 2 minutes they take longer than the first person)\
-Highest score wins, having the same score results in a draw
